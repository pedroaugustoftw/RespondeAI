RespondeAI - executável portátil para Windows 64 bits

1. Baixe RespondeAI-Windows-x64.exe nas Releases publicadas pelo autor no GitHub.
   A v1.0.1 não inclui uma versão nativa para Windows ARM64.
2. Abra o arquivo baixado. Não é necessário instalar Python ou um instalador.
3. Em Configurações > API, escolha Groq ou Gemini, informe sua chave e modelos,
   e clique em Salvar. Cada computador precisa de sua própria configuração.
4. Clique em Iniciar para selecionar uma pergunta na tela.

O OCR e seus modelos estão dentro do executável e funcionam localmente.
A resposta de Groq/Gemini requer internet e uma chave válida com cota disponível.
O programa não inclui as chaves, o histórico ou as configurações do desenvolvedor.

A primeira abertura pode demorar alguns segundos: o arquivo único extrai os
componentes para uma pasta temporária do Windows. O histórico e as configurações
ficam em %LOCALAPPDATA%\RespondeAI; as chaves ficam no cofre do Windows.

Os executáveis são compilados e disponibilizados pelo autor:
https://github.com/pedroaugustoftw/RespondeAI/releases

Para executar o código Python, consulte o README.md do repositório.
